Frozen analysis plan written 09 October 2026, before this experiment's training; not preregistered. The user supplied the full implementation specification in block_shuffle_supplied_spec.md and authorized one GPU execution after smoke tests.

Control: same full 2000x1000 field split into two nonoverlapping1000x1000 halves, resized224x224, official grass-adapted student I-JEPAH/14 frozen. Treatments: independently permute4x4 or10x10 equal blocks in each original half before resize. Each training original image/epoch uses a treatment with probability0.35. Four deterministic SHA/source/view/variant seeds paired with quarter-turn0/90/180/270. Identity/unshuffled validation and inference throughout. No reflections, crops, photometric augmentation or cross-image mixing. Four cached views are not independent measurements.
